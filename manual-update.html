CGTN Tech Radar 手动更新

定时飞书会自动运行。若早晨、下午或晚上没有收到，可以在手机上打开本页，点击 GitHub Actions 手动触发。

手动触发更新 打开后点 “Run workflow”，会重新抓取、更新网页并推送飞书 查看当前看板 打开最新 CGTN Tech Desk Daily Radar 网页 查看运行记录 检查最近一次是否成功、失败或仍在运行

手机首次使用需要登录 GitHub。进入 workflow 页面后，如果没有看到按钮，点右上角浏览器菜单选择桌面版网页。手动触发属于 workflow_dispatch，成功后也会发送一条飞书测试消息。
